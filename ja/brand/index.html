陰影Schatten · Brand Concept

陰影とは、光の不在ではなく、
紙と墨のあいだに生まれる階調である。

Schatten はドイツ語で「影」。ポートフォリオサイトのブランドコンセプト『陰翳礼讃』(谷崎潤一郎)を、ページ単位ではなくボタンや文字などのコンポーネント単位のデザイントークンとして実装したものである。

色

四つの色は、和の語彙でできている

Schatten の primitive は色名からして和語である。数値は v1.0.0 の実トークン(yasmro/schatten の src/core/tokens/primitives.css)。

墨は寒く、紙は暖かい ― 彩度は同じ

sumi と alabaster は明度も彩度も同一で、色相だけが 250 と 70 で正反対。ほぼ無彩に見えて、墨は青へ、紙は黄へ倒れている。

季節

八つの季節、ひとつの明度

季節(Special テーマ)は --color-theme-* のランプだけを替える。500 段はすべて L 64%、700 段はすべて L 46% に固定されていて、動くのは色相と彩度だけだ。区切りの日付は、古典的な八節(四立と二至二分)と一致する。

  • 立春2/4h12
  • 春分3/21h138
  • 立夏5/6h162
  • 夏至6/21h45
  • 立秋8/7h230
  • 秋分9/23h70
  • 立冬11/7h250
  • 冬至12/22h255

巡る季節と、動かない可読性。八節は色だけを運び、明度の梯子には触れない。

書体

二つの言語を、同時に話す

構造は西洋の工学語彙 ― shadcn / Radix / OKLCH / BEM / CVA。表層は和の美学語彙 ― 朱・墨・和紙・藍・八節。どちらも他方の装飾ではない。

この二重性は、名前や色名だけにとどまらない。組版そのものに実装されている。sans も serif も、欧文フェイスと和文フェイスを明示的に対にしてひとつのスタックを組む。バイリンガルであることが、既定の状態。
