角丸

角丸は絶対的な大きさではなく、面の種類で選ぶ。コンポーネントでは primitive の段階ではなくセマンティックトークンを使う。

尺度

--radius-full はどの要素もピル形や円にするための特別な値で、他は固定の長さである。

  • --radius-none0
  • --radius-sm0.125rem
  • --radius-md0.375rem
  • --radius-lg0.5rem
  • --radius-xl0.75rem
  • --radius-2xl1rem
  • --radius-full9999px

セマンティックトークン

それぞれ上の段階の別名である。「定義のみ」のトークンは、使うコンポーネントがまだない。

  • --radius-pillチップやトグル: Badge、Radio、Switch
    適用済み
  • --radius-controlボタンとテキスト入力。現在の Button と Input は角が四角い
    定義のみ
  • --radius-surface大きな浮遊面。現在の Dialog と Select の中身は角が四角い
    定義のみ
