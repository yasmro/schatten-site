DateCalendar

フォーム

常に表示される月のカレンダーで、日付をひとつ選ぶ。期間を選ぶときは DateRangeCalendar を使う。

2026年11月
日月火水木金土
12345
6789101112

使い方

import { DateCalendar } from '@yasmro/schatten'

<DateCalendar defaultValue="2026-11-14" onValueChange={setDate} />

ガイドライン

コントロールの選び方

  • 予約ページのように、カレンダーを常にページに出しておくときに DateCalendar を使う。フォームの入力欄には、入力とポップオーバーのカレンダーを組み合わせた DatePicker を使う。
  • 期間には DateRangeCalendar を使う。値が日付ではなく { from, to } なので、mode のような prop ではなく別のコンポーネントになっている。

値と言語

  • 値は Date オブジェクトではなく YYYY-MM-DD の文字列で、タイムゾーンで日付が 1 日ずれることはない。変換には @yasmro/schatten/date の toDate / toDateString を使う。
  • locale を指定したら、labels も同じ言語で渡す。渡さないと、スクリーンリーダーが 2 つの言語を混ぜて読み上げる。
  • サーバーで描画するときは today か defaultMonth を渡す。サーバーとブラウザで、最初に表示する月がそろう。
