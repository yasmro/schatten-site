Color

Colors are inspired by Japanese calligraphy: ink on paper. They come in two tiers: primitives say what a color is, and semantic colors say what it is for. Components use the semantic tier.

PrimitiveSemantic

Primitive

Primitives carry no use, and they do not change between light and dark mode.

Ink & paper

Names for the colors of ink and paper. Most ink tokens are aliases of a rung on a scale; the paper tones have values of their own. They still describe a color, not a use.

  • --ink-blackDarkest ink→ --sumi-900
  • --ink-darkSecondary ink→ --sumi-700
  • --ink-mediumMedium ink→ --sumi-600
  • --ink-faintFaint ink→ --sumi-500
  • --ink-lightLight ink→ --sumi-400
  • --ink-subtleFaintest ink. Too light for AA text→ --sumi-300
  • --paper-whiteLightest paper
  • --paper-warmWarm paper
  • --paper-creamCream paper

Ink & paper for dark mode

The dark-mode counterparts. Semantic colors switch to these in dark mode.

  • --ink-black-invertedStrongest ink on dark paper→ --alabaster-200
  • --ink-dark-invertedSecond ink on dark paper→ --alabaster-300
  • --ink-medium-invertedMedium ink on dark paper→ --alabaster-400
  • --ink-light-invertedLight ink on dark paper→ --alabaster-500
  • --ink-subtle-invertedFaintest ink on dark paper→ --alabaster-600
  • --paper-white-invertedDark paper for surfaces
  • --paper-warm-invertedDark paper for the page
  • --paper-cream-invertedLightest dark paper

Semantic

Each semantic color points at a primitive. The target changes with the mode, which is how components follow light and dark with no code of their own. Each row shows both modes, whichever you are viewing.

Tokens by use

Surfaces & foreground

  • --color-backgroundPage backgroundLight → --paper-warmDark → --paper-warm-inverted
  • --color-surfaceCard and container surfacesLight → --paper-whiteDark → --paper-white-inverted
  • --color-surface-hoverHover state for surfacesLight → --alabaster-200Dark → --paper-cream-inverted
  • --color-foregroundPrimary textLight → --ink-blackDark → --ink-black-inverted
  • --color-foreground-mutedSecondary and helper text. Meets AA for small text (≥ 4.5:1)Light → --ink-mediumDark → --ink-medium-inverted
  • --color-foreground-subtleTertiary text, for large or incidental text only (AA large text, 3:1)Light → --ink-faintDark → --ink-light-inverted

Inverted foreground

For text on saturated or dark containers, such as a solid Toast or Callout. Mirrors the foreground hierarchy.

  • --color-inverted-foregroundPrimary text on a saturated surfaceLight → --paper-whiteDark → --paper-white-inverted
  • --color-inverted-foreground-mutedSecondary text on a saturated surfaceLight → --alabaster-300Dark → --alabaster-700
  • --color-inverted-foreground-subtleTertiary text on a saturated surfaceLight → --alabaster-400Dark → --alabaster-600

Solid

For filled components. These tokens consume rungs of the Theme scale, so a seasonal theme recolors them.

  • --color-solidFilled component background, such as a primary ButtonLight → --color-theme-700Dark → --color-theme-300
  • --color-solid-hoverHover state for filled componentsLight → --color-theme-900Dark → --color-theme-100
  • --color-solid-foregroundText on filled componentsLight → --color-theme-100Dark → --color-theme-800
  • --color-solid-foreground-hoverText on filled components, on hoverLight → --color-theme-300Dark → --color-theme-700

Brand

The two brand colors. Unlike state tokens, these name the color itself (朱 vermillion, 藍 indigo) rather than a meaning. Use them for deliberate brand emphasis.

  • --color-vermillionBrand color: 朱 vermillionLight → --vermillion-600Dark → --vermillion-400
  • --color-vermillion-foregroundText on vermillionLight → --paper-whiteDark → --paper-white-inverted
  • --color-indigoBrand color: 藍 indigoLight → --indigo-600Dark → --indigo-400
  • --color-indigo-foregroundText on indigoLight → --paper-whiteDark → --paper-white-inverted

Border & ring

  • --color-borderDefault border for dividersLight → --gray-200Dark → --gray-700
  • --color-border-strongStrong border, such as a secondary ButtonLight → --ink-blackDark → --ink-black-inverted
  • --color-ringFocus ringLight → --ink-blackDark → --ink-black-inverted
  • --color-ring-offsetGap between a control and its focus ringLight → --paper-warmDark → --paper-warm-inverted

How state tokens work

Each state has five tokens: base for fills, borders and icons, hover, foreground for text on the base, subtle for a faint background, and emphasis for colored text. Use emphasis for text: base as text falls just under AA for small text.

Destructive

For destructive actions. Shares the red primitive with error, but the meaning differs.

  • --color-destructivedestructive base colorLight → --red-600Dark → --red-500
  • --color-destructive-hoverHover state for destructiveLight → --red-700Dark → --red-400
  • --color-destructive-foregroundText on the base colorLight → --paper-whiteDark → --paper-white-inverted
  • --color-destructive-subtleFaint tinted backgroundLight → --red-50Dark → --red-900
  • --color-destructive-emphasisReadable colored text on subtle or light surfacesLight → --red-700Dark → --red-400

Non-interactive states

For controls that cannot be used (disabled) or only display a value (readOnly). There is no hover slot.

  • --color-surface-disabledBackground of disabled controls: cool and mutedLight → --gray-100Dark → --gray-800
  • --color-foreground-disabledText and icons of disabled controlsLight → --gray-500Dark → --gray-500
  • --color-border-disabledBorder of disabled controlsLight → --gray-200Dark → --gray-700
  • --color-surface-readonlyBackground of readOnly controls: warm and staticLight → --alabaster-100Dark → --alabaster-800
  • --color-border-readonlyBorder of readOnly controlsLight → --gray-200Dark → --gray-700
