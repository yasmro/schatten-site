Color

Colors come in three layers. Primitive holds the raw values, Theme holds the ramp a seasonal theme swaps, and Semantic names each color by its use. Components use Semantic and Theme, never Primitive.

  1. PrimitiveRaw values
  2. SemanticNamed by use
  3. ComponentsFills, borders, text
  1. PrimitiveRaw values
  2. ThemeRamp a season swaps
  3. Semantic (solid)and Table

47 of the 51 semantic colors point at a Primitive directly. Only the 4 solid colors go through Theme, and among components only Table uses Theme directly.

Click a swatch to copy its CSS custom property, such as --sumi-500. Names under the swatches leave out the leading --. Hex values are converted from OKLCH; a value marked ≈ is outside sRGB, so its hex is approximate.

Semantic

Each color is named by its use and points at a Primitive or Theme step. The target changes with the mode. In each swatch, the left half is light mode and the right half is dark mode.

Surfaces & foreground

  • Page backgroundLight → paper-warm · #F5F3F0Dark → paper-warm-inverted · #1E1E1C
  • Card and container surfacesLight → paper-white · #FAFAFADark → paper-white-inverted · #1A1A1A

How state tokens work

Each state has five tokens: base for fills, borders and icons, hover, foreground for text on the base, subtle for a faint background, and emphasis for colored text. Use emphasis for text: base as text falls just under AA for small text.
