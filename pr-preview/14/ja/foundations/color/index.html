色

色の着想は書、つまり紙に墨である。色は 2 層に分かれていて、プリミティブは「何色か」を、セマンティックは「何に使うか」を表す。コンポーネントはセマンティックの層を使う。

墨と紙

墨と紙の色に付けた名前である。墨の多くは階調の 1 段の別名で、紙は固有の値を持つ。どちらも用途ではなく色を表す。

  • --ink-black最も濃い墨→ --sumi-900
  • --ink-dark二番目に濃い墨→ --sumi-700
  • --ink-medium中間の墨→ --sumi-600
  • --ink-faint淡い墨→ --sumi-500
  • --ink-light薄い墨→ --sumi-400
  • --ink-subtle最も薄い墨。文字には薄すぎて AA を満たさない→ --sumi-300
  • --paper-white最も明るい紙
  • --paper-warm暖かみのある紙
  • --paper-creamクリーム色の紙

ダークモードの墨と紙

ライト用の墨と紙に対応する、ダークモード用の色。セマンティックカラーはダークモードでこれらに切り替わる。

  • --ink-black-inverted暗い紙の上で最も強い墨→ --alabaster-200
  • --ink-dark-inverted暗い紙の上で二番目に強い墨→ --alabaster-300
  • --ink-medium-inverted暗い紙の上の中間の墨→ --alabaster-400
  • --ink-light-inverted暗い紙の上の薄い墨→ --alabaster-500
  • --ink-subtle-inverted暗い紙の上で最も薄い墨→ --alabaster-600
  • --paper-white-inverted面に使う暗い紙
  • --paper-warm-invertedページに使う暗い紙
  • --paper-cream-inverted暗い紙の中で最も明るい色

Semantic

セマンティックカラーはそれぞれプリミティブを参照している。参照先がモードで切り替わるので、コンポーネントはコードなしでライト・ダークに追従する。各行には、表示中のモードに関係なく両方のモードを示す。

用途別のトークン

面と前景

  • --color-backgroundページの背景ライト → --paper-warmダーク → --paper-warm-inverted
  • --color-surfaceカードやコンテナの面ライト → --paper-whiteダーク → --paper-white-inverted
  • --color-surface-hover面のホバー状態ライト → --alabaster-200ダーク → --paper-cream-inverted
  • --color-foreground主要な文字ライト → --ink-blackダーク → --ink-black-inverted
  • --color-foreground-muted補助的な文字。小さな文字でも AA を満たす(4.5:1 以上)ライト → --ink-mediumダーク → --ink-medium-inverted
  • --color-foreground-subtle三番目に目立つ文字。大きな文字や付随的な文字に限る(AA の大きな文字の基準 3:1)ライト → --ink-faintダーク → --ink-light-inverted

反転した前景

solid の Toast や Callout など、彩度の高い面や暗い面の上の文字に使う。前景と同じ階層を持つ。

  • --color-inverted-foreground彩度の高い面の上の主要な文字ライト → --paper-whiteダーク → --paper-white-inverted
  • --color-inverted-foreground-muted彩度の高い面の上の補助的な文字ライト → --alabaster-300ダーク → --alabaster-700
  • --color-inverted-foreground-subtle彩度の高い面の上で三番目に目立つ文字ライト → --alabaster-400ダーク → --alabaster-600

Solid

塗りのコンポーネントに使う。Theme の階調を参照しているので、季節テーマを適用すると色が変わる。

  • --color-solid塗りのコンポーネントの背景。primary の Button などライト → --color-theme-700ダーク → --color-theme-300
  • --color-solid-hover塗りのコンポーネントのホバー状態ライト → --color-theme-900ダーク → --color-theme-100
  • --color-solid-foreground塗りのコンポーネントの上の文字ライト → --color-theme-100ダーク → --color-theme-800
  • --color-solid-foreground-hoverホバー時の、塗りのコンポーネントの上の文字ライト → --color-theme-300ダーク → --color-theme-700

ブランド

ふたつのブランドカラー。状態トークンと違い、意味ではなく色そのもの(朱、藍)を名前にしている。意図してブランドを強調するときに使う。

  • --color-vermillionブランドカラー: 朱ライト → --vermillion-600ダーク → --vermillion-400
  • --color-vermillion-foreground朱の上の文字ライト → --paper-whiteダーク → --paper-white-inverted
  • --color-indigoブランドカラー: 藍ライト → --indigo-600ダーク → --indigo-400
  • --color-indigo-foreground藍の上の文字ライト → --paper-whiteダーク → --paper-white-inverted

ボーダーとリング

  • --color-border区切り線に使う標準のボーダーライト → --gray-200ダーク → --gray-700
  • --color-border-strong強いボーダー。secondary の Button などライト → --ink-blackダーク → --ink-black-inverted
  • --color-ringフォーカスリングライト → --ink-blackダーク → --ink-black-inverted
  • --color-ring-offsetコントロールとフォーカスリングの間の余白ライト → --paper-warmダーク → --paper-warm-inverted

状態トークンの仕組み

各状態には 5 つのトークンがある。base は塗り・ボーダー・アイコン、hover はホバー、foreground は base の上の文字、subtle は淡い背景、emphasis は色の付いた文字に使う。base を文字に使うと、小さな文字の AA 基準にわずかに届かない。

Destructive

破壊的な操作に使う。error と同じ red の primitive を使うが、意味は別である。

  • --color-destructivedestructive の基本色ライト → --red-600ダーク → --red-500
  • --color-destructive-hoverdestructive のホバー状態ライト → --red-700ダーク → --red-400
  • --color-destructive-foreground基本色の上の文字ライト → --paper-whiteダーク → --paper-white-inverted
  • --color-destructive-subtle淡い色付きの背景ライト → --red-50ダーク → --red-900
  • --color-destructive-emphasissubtle や明るい面の上で読める、色の付いた文字ライト → --red-700ダーク → --red-400

Error

  • --color-error-foreground基本色の上の文字ライト → --paper-whiteダーク → --paper-white-inverted

操作できない状態

使えないコントロール(disabled)や、値を表示するだけのコントロール(readOnly)に使う。hover はない。

  • --color-surface-disableddisabled の背景。寒色で控えめライト → --gray-100ダーク → --gray-800
  • --color-foreground-disableddisabled の文字とアイコンライト → --gray-500ダーク → --gray-500
  • --color-border-disableddisabled のボーダーライト → --gray-200ダーク → --gray-700
  • --color-surface-readonlyreadOnly の背景。暖色で静的ライト → --alabaster-100ダーク → --alabaster-800
  • --color-border-readonlyreadOnly のボーダーライト → --gray-200ダーク → --gray-700

組み合わせ

トークンの組み合わせ方。テーマを切り替えると両方のモードを比べられる。

disabled と readOnly

disabled は寒色の控えめな配色で「使えない」ことを示す。readOnly は暖色の配色で「値は読めるが変更できない」ことを示す。

disabled素早い茶色の狐が怠惰な犬を飛び越える
readOnly素早い茶色の狐が怠惰な犬を飛び越える

塗り

X を背景に、X-foreground を文字に使う。

destructive素早い茶色の狐が怠惰な犬を飛び越える
error素早い茶色の狐が怠惰な犬を飛び越える
success素早い茶色の狐が怠惰な犬を飛び越える
warning素早い茶色の狐が怠惰な犬を飛び越える
info素早い茶色の狐が怠惰な犬を飛び越える

淡色

X-subtle を背景に、X-emphasis を文字に使う。

destructive素早い茶色の狐が怠惰な犬を飛び越える
error素早い茶色の狐が怠惰な犬を飛び越える
success素早い茶色の狐が怠惰な犬を飛び越える
