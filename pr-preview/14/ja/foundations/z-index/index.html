重なり順

Schatten は z-index の 0–100 をオーバーレイ用に予約している。Dialog の中で開いた Tooltip が必ず手前に描かれるのはこのためだ。z-index はどちらが手前かを決め、影は高さの見え方を示すだけである。

尺度

値は重なり順に沿って増える。下の 4 つはライブラリでは使っておらず、ページ側の要素のために空けてある。

  • --z-base0通常の流れ
  • --z-dropdown10ページ側用に予約
  • --z-sticky20ページ側の sticky 要素用に予約
  • --z-fixed30ページ側の fixed 要素用に予約
  • --z-modal-backdrop40Dialog のオーバーレイ
  • --z-modal50Dialog の中身
  • --z-popover60Select と Popover の中身
  • --z-tooltip70Tooltip
  • --z-toast80Toast。最前面

描画順

DOM の順序に関係なく、後のトークンが手前に描かれる。この例の DOM は手前から奥の順に並んでいるが、それでも描画はトークンの順になる。

--z-toast
--z-tooltip
--z-popover
--z-modal
--z-modal-backdrop
