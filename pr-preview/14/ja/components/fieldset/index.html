FieldSet

フォーム

関連するフィールドをひとつの legend でまとめ、無効状態やエラー状態を共有する。

名前

使い方

import { Field, FieldSet, Input } from '@yasmro/schatten'

<FieldSet legend="Name" direction="row">
  <Field label="First name" flexGrow={1}><Input /></Field>
  <Field label="Last name" flexGrow={1}><Input /></Field>
</FieldSet>

ガイドライン

グループ化

  • 住所のように、ひとつの設問を構成するフィールドには legend を付ける。レイアウトだけが目的なら省く。
  • 特定のフィールドに属さない問題は、グループの error で伝える。
  • 狭い画面でも収まるよう、direction="row" では wrap も指定する。
