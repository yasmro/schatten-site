色

色は 3 層でできている。Primitive は生の値を、Theme は季節テーマで差し替わる階調を持ち、Semantic は用途で色に名前を付ける。コンポーネントは Semantic と Theme を使い、Primitive は直接使わない。

  1. Primitive生の値
  2. Semantic用途で名付けた色
  3. コンポーネント塗り・線・文字
  1. Primitive生の値
  2. Theme季節で差し替わる階調
  3. Semantic の solid 系と Table

Semantic の 51 色のうち 47 色は、Primitive を直接参照する。Theme を経由するのは solid 系の 4 色だけで、コンポーネントで Theme を直接使うのは Table だけである。

見本をクリックすると、--sumi-500 のような CSS 変数名をコピーできる。見本の下の名前は、先頭の -- を省いて示す。HEX は OKLCH から変換した値で、≈ の付いた値は sRGB の範囲外にあるため近似値になる。

Semantic

用途で名付けた色で、それぞれ Primitive か Theme の段を参照する。参照先はモードで切り替わる。見本の左半分がライト、右半分がダーク。

面と前景

  • ページの背景ライト → paper-warm · #F5F3F0ダーク → paper-warm-inverted · #1E1E1C
  • カードやコンテナの面ライト → paper-white · #FAFAFAダーク → paper-white-inverted · #1A1A1A
  • 面のホバー状態ライト → alabaster-200 · #E6E0DAダーク → paper-cream-inverted · #44403A
  • 主要な文字ライト → ink-black · #0E1216ダーク → ink-black-inverted · #E6E0DA
  • 補助的な文字。小さな文字でも AA を満たす(4.5:1 以上)ライト → ink-medium · #595E63ダーク → ink-medium-inverted · #A6A09B
  • 三番目に目立つ文字。大きな文字や付随的な文字に限る(AA の大きな文字の基準 3:1)ライト → ink-faint · #767B80ダーク → ink-light-inverted · #7E7974

反転した前景

solid の Toast や Callout など、彩度の高い面や暗い面の上の文字に使う。前景と同じ階層を持つ。
  • 彩度の高い面の上の主要な文字ライト → paper-white · #FAFAFAダーク → paper-white-inverted · #1A1A1A
  • 彩度の高い面の上の補助的な文字ライト → alabaster-300 · #CCC6C0ダーク → alabaster-700 · #433F3A
  • 彩度の高い面の上で三番目に目立つ文字ライト → alabaster-400 · #A6A09Bダーク → alabaster-600 · #615D58

状態トークンの仕組み

各状態には 5 つのトークンがある。base は塗り・ボーダー・アイコン、hover はホバー、foreground は base の上の文字、subtle は淡い背景、emphasis は色の付いた文字に使う。base を文字に使うと、小さな文字の AA 基準にわずかに届かない。

組み合わせ

トークンの組み合わせ方。テーマを切り替えると両方のモードを比べられる。

disabled と readOnly

disabled は寒色の控えめな配色で「使えない」ことを示す。readOnly は暖色の配色で「値は読めるが変更できない」ことを示す。

disabled素早い茶色の狐が怠惰な犬を飛び越える
readOnly素早い茶色の狐が怠惰な犬を飛び越える

塗り

X を背景に、X-foreground を文字に使う。

destructive素早い茶色の狐が怠惰な犬を飛び越える
error素早い茶色の狐が怠惰な犬を飛び越える
success素早い茶色の狐が怠惰な犬を飛び越える
warning素早い茶色の狐が怠惰な犬を飛び越える
info素早い茶色の狐が怠惰な犬を飛び越える
