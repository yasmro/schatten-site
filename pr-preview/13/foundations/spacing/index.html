Spacing

The scale is built on a 4px base. Use it instead of arbitrary pixel values, so every layout lands on the same rhythm.

Scale

These are the public, recommended values. Half steps such as --spacing-0-5 and odd steps such as --spacing-7 exist for use inside components, so application code does not normally reach for them.

Stay on the scale

  • Off-scale values render fine, so nothing stops them: this is a rule to keep. Choose the nearest recommended step.

No layout components

Schatten deliberately ships no Stack or HStack. Compose spacing directly with flex and gap on these tokens, so layout reads inline at the call site.
