Table

Data display

A semantic table for tabular data. It provides the look only: no sorting, filtering or pagination.

Invoices
ItemAmount
INV-001¥12,000
INV-002¥980

Usage

import { Table, TableBody, TableCaption, TableCell, TableHead, TableHeader, TableRow } from '@yasmro/schatten'

<Table>
  <TableCaption>Invoices</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead scope="col">Number</TableHead>
      <TableHead scope="col" align="end">Amount</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>INV-001</TableCell>
      <TableCell align="end">¥12,000</TableCell>
    </TableRow>
  </TableBody>
</Table>

Guidelines

Accessible structure

  • Name the table with TableCaption.
  • Pass scope="col" or scope="row" to TableHead. Table does not set it for you.

Alignment

  • Align numbers to the end, in the head and the cells alike, so digits line up for comparison.

Interactive rows

  • hoverable and selected change only the look. If a row is interactive, add a real button or link to it.
